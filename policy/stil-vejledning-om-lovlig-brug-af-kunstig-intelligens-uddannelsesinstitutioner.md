# Summary

Legal guidance, prepared with the government's legal adviser, for education institutions procuring or
using AI, with most weight on generative AI. It sets out seven steps and includes the AI Act's
timeline and a mapping template [1].

# Facts

| | |
|---|---|
| Form | guidance (legal) |
| Domain | education |
| Level | primary and lower secondary; upper secondary; vocational |
| Issued by | Styrelsen for It og Læring (STIL), Børne- og Undervisningsministeriet; prepared with Kammeradvokaten |
| Force | guidance — the institutions carry the responsibility |
| Date | published 28 May 2025 |
| Audience | mainly compliance staff; also teachers and leaders |
| Scope | GDPR and the EU AI Act when schools and institutions use AI |
| Access | open |
| Status | Active |

# Key provisions

- Seven steps: map AI solutions, clarify the institution's role, assess lawfulness, assess risk, inform data subjects, set policies, train staff.
- Includes the AI Act's timeline of application and a template for mapping AI solutions.
