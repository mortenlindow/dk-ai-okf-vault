# Summary

The national code for research integrity, updated in January 2026 and replacing the 2014 code. AI
was one of five areas the revision focused on. The code applies to researchers and research
institutions in all fields and takes full effect when institutions build it into their own
frameworks [1].

| Status | Active |

# Key provisions

- Use of AI in communication and publication should be declared, following established national and international guidelines.
- Institutions should follow established guidelines on AI in relation to authorship.
- Because AI changes too fast for the code to set its own rules, it points to an overview of guidelines kept by the agency.
- The glossary defines AI and generative AI.
