# Summary

The peer-review guide for the foundation's 13th round of Centres of Excellence lists a declaration
of the use of generative AI among the required parts of a full proposal [1].

# Facts

| | |
|---|---|
| Form | rules (call documentation) |
| Domain | research |
| Issued by | [Danmarks Grundforskningsfond](/organisations/funders/dnrf.md) |
| Force | binding — a required part of the proposal |
| Date | 13th round; file dated February 2026 |
| Audience | peer reviewers, and by extension applicants |
| Scope | A required declaration of generative-AI use |
| Access | open |
| Status | Active |

# Key provisions

- A full proposal must include a declaration of the use of generative AI.

# Notes

The guide does not set out what the declaration must contain or how reviewers should weigh it, as read on 2026-11-02.
