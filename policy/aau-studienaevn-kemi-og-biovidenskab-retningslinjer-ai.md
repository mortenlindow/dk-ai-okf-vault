# Summary

Guidelines from one study board showing how the university-wide rule is put into practice at the
study-board layer [1].

# Facts

| | |
|---|---|
| Form | guideline |
| Domain | education |
| Level | higher education |
| Issued by | Studienævnet for Kemi og Biovidenskab, [Aalborg University](/organisations/academic/aau.md) |
| Force | recommendation, with some mandatory wording |
| Date | February 2025 |
| Audience | students and course holders |
| Scope | AI in teaching, supervision and project work |
| Access | open |
| Status | Active |

# Key provisions

- AI use in projects should be discussed with the supervisor and briefly declared in the report.
- Course holders must state in the learning platform whether and how AI is allowed, and decide its use at exams.
