# Summary

An exam trial in marketing (*afsætning A*) on the higher commercial examination, testing an exam form in
which generative AI is part of the exam, using a centrally set case. It continues a 2025 trial [1].

# Facts

| | |
|---|---|
| Form | exam rules (trial) |
| Domain | education |
| Level | upper secondary |
| Issued by | Styrelsen for Undervisning og Kvalitet (STUK), Børne- og Undervisningsministeriet |
| Force | binding for the enrolled classes |
| Date | school year 2026/27, exams in summer 2027 |
| Audience | about 25 participating institutions |
| Scope | An exam form with generative AI built in |
| Access | open |
| Status | Active |

# Key provisions

- Two sub-trials: a group exam, and an individual oral exam with a report written in groups.
- Enrolled classes must sit the trial exam.
