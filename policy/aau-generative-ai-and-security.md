# Summary

The information-security function's rules tying generative-AI tools to the university's data
classification, for staff, students and researchers [1].

# Key provisions

- Free consumer chat tools are limited to the lowest data class.
- The enterprise Copilot is allowed up to the second class but not for personal data; a named tool is allowed up to the third class for research.
- Health data are classified in the higher classes; self-hosted AI needs an IT-security assessment for higher classes.
