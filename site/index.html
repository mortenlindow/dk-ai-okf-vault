Bodies, issuers and suppliers are welcome to correct their own entries. Requests go through GitHub issues: a free GitHub account is needed, and issues are public. Method

Collected once, recorded as files, shown many ways

The pages are views onto one store of plain-text files. The files are the record; the pages are one way of reading them.

  1. 1 · Collect

    Read at the source

    Public pages and documents are read where they are published: rosters, member lists, event programmes, instruction databases, funders' terms. Every fact is dated and cited. Nothing behind a login is read; such documents are recorded by title only.

  2. 2 · Record

    One file per concept, in OKF

    Each body, network, rule or course becomes one Markdown file in the Open Knowledge Format: a small typed header, a table of facts, plain links to related files, and citations. The file's path is its identity.

  3. 3 · Display

    Pages drawn from the files

    The registers on this site are built from the vault. The rules page is generated directly from the policy files, so the page and the record match.

  4. 4 · Analyse

    Open for further work

    The whole vault is on GitHub as plain text. People can read and correct it; LLMs and scripts can load it whole, follow its links and query it, without scraping these pages.

The vault is open. Browse, download or clone it at github.com/mortenlindow/dk-ai-okf-vault. Start at index.md; the conventions are in CLAUDE.md, and the dated record of every collection pass is in log.md. To load it into an LLM, give it the repository or a folder such as policy/.
