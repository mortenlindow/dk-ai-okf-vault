# Organisations

Durable bodies whose existence does not depend on AI — universities, faculties,
departments, hospitals, regions, municipalities, ministries, agencies, foundations,
associations and non-profit clusters. All one `type: Organisation`, distinguished by a
`| Kind |` row.

**These are a supporting cast list, not a collection target.** They exist so
[initiatives](../initiatives/index.md) have something to link to. Never write one
speculatively — write it when a second concept needs to link to it, or when it holds a
fact we need (a succession, a funding role). This set should stay small.

The master cut: *would this body exist if AI had never been invented?* Yes → here.
No → [initiatives](../initiatives/index.md).

## Sections

* [Academic](academic/index.md) - universities, faculties, departments.
* [Health](health/index.md) - regions, hospitals, national health-data bodies.
* [Public](public/index.md) - ministries, agencies, KL, Danske Regioner, municipalities.
* [Funders](funders/index.md) - foundations, state funds, Nordic and EU funders, clusters.

Filing tiebreak: a body goes where its **funding and accountability** sit. If filing takes
more than ten seconds, use `public/` and note the ambiguity — these are link targets, not
research subjects.
