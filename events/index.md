# Events

Dated convenings — launch meetings, conferences, workshops, hackathons — and the
[series](series/index.md) they belong to.

**Event gate (three-part):** a file requires (a) a date, (b) an in-scope named convening
body, and (c) a published programme or named speakers. Fails any of the three → a row in
the convener's `# Activities` table, not a file. This keeps the folder from becoming a
calendar scrape.

Instances are date-prefixed (`2026-10-27-…`) so they sort chronologically and their
identity is permanent. **A future event does not move when it happens** — flip `Status`
from `Announced` to `Held`, add `# Outcome`, and log an update.
