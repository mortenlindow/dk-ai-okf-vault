# Snapshots

Dated snapshots of a state that has **no single durable subject** — for example, "the
Danish public AI funding landscape, September 2026".

**Kept near-empty by design.** Entities are durable and updated in place; they are never
snapshotted into new files. If you are about to write a snapshot of *one* body, you want
to edit that body's concept instead.
