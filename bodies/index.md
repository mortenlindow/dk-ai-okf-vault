# Governance bodies

Standing organs that govern or oversee another concept: steering committees, coordination
groups, boards, advisory councils.

**Rare by design.** A governance body earns its own file only when it has ≥5 named
members, **or** published rules of procedure or a mandate, **or** a membership spanning
organisations we want linked as a graph. Otherwise it stays a `# Governance` table inside
its parent initiative.

This is the **canonical home for seats and terms** — who holds which role, for how long.
Person concepts carry an undated link back, never the term dates.
